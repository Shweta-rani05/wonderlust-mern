
# 🌍 Wonderlust – MERN Hotel Booking Platform

A full-stack **MERN-based hotel booking platform** engineered to demonstrate scalable backend architecture, secure authentication, and real-world application workflows.

🔗 **Live Demo:** https://wonderlust-mern-kj89.onrender.com/
💻 **Source Code:** https://github.com/Shweta-rani05/wonderlust-mern

---

## 🚀 Overview

Wonderlust is a production-oriented web application that enables users to explore, create, and manage property listings with a seamless booking-like experience. The platform is built with a strong focus on **backend engineering**, implementing RESTful APIs, secure session handling, and efficient database design.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose ODM)
* **Frontend:** EJS, Bootstrap
* **Authentication:** Passport.js (Local Strategy)
* **Session Management:** express-session, connect-mongo
* **Validation:** Joi
* **Cloud Storage:** Cloudinary
* **Maps & Location:** Mapbox API

## ✨ Key Features

* 🔐 Secure user authentication & authorization (Passport.js)
* 🏠 CRUD operations for property listings
* ⭐ Review and rating system
* 🔍 Search functionality for destinations
* ☁️ Image upload & storage using Cloudinary
* 🗺️ Location integration using Mapbox
* ⚙️ RESTful API architecture with middleware handling

---

## 🧠 Backend Highlights

* Designed modular and scalable **Express routing structure**
* Implemented **middleware-based request lifecycle handling**
* Integrated **server-side validation using Joi**
* Managed sessions securely with **MongoDB-backed session store**
* Ensured clean error handling using centralized middleware

## 🌐 Deployment

The application is deployed on **Render** and uses **MongoDB Atlas** for database hosting.
